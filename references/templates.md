# 8 个场景模板

每个模板只规定**段落顺序**和**必须出现的信息**。套话、感叹、求互动的句子一律不写。

---

## 1. 探店

```
标题：地点 + 一个具体判断（好/不好/别点什么）
① 一句结论（值不值得来，多少钱）
② 点了什么：菜名 + 价格 + 一句口感（可验证的细节）
③ 环境与等待：等多久、有没有座、几点人少
④ 一个坑：哪个菜别点 / 哪个时段别来
⑤ 适合谁：几个人、什么场景来合适
标签：#城市 + #品类 + #人均价位 + #商圈
```

## 2. 测评（单品 / 单工具）

```
标题：价格 + 用了多久 + 结论
① 结论前置：留还是退，一句话
② 用了多久、什么场景下用的
③ 三个具体表现：好的两条 + 差的一条，都要有数字或对比对象
④ 谁适合买 / 谁别买
⑤ 购买渠道与到手价
标签：#品类 + #价位段 + #对比对象 + #使用场景
```

## 3. 教程（怎么做成一件事）

```
标题：时间 + 结果（10 分钟做完一周午饭）
① 最终成果一句话 + 需要多久
② 需要准备什么（数量、型号、在哪买）
③ 分步骤：3–6 步，每步一个动作 + 一个易错点
④ 我踩过的坑：1–2 条
⑤ 一次能出多少份 / 能省多少钱
标签：#技能 + #人群 + #具体问题
```

## 4. 避坑（我错了，别跟着错）

```
标题：别做什么 + 损失了多少
① 我踩的坑，一句说完（含金额或时间成本）
② 为什么会踩：当时的判断依据是什么
③ 正确的做法，3 条以内
④ 已经踩了怎么补救
⑤ 一句提醒：什么情况下这个坑会复现
标签：#避坑 + #品类 + #人群
```

## 5. 好物清单

```
标题：价格区间 + 数量 + 解决什么问题
① 一句总述：这批东西解决的是哪个具体麻烦
② 逐条：名称 + 价格 + 一句话理由（各自不同，不要都写"好用"）
③ 只推荐一个最值的，说明为什么是它
④ 哪几个可以不买（省钱信息最有价值）
标签：#清单 + #价位 + #空间/场景
```

## 6. plog / 日常记录

```
标题：时间 + 地点 + 一个情绪落点（不要抽象）
① 一句当时的画面（几点、在哪、在做什么）
② 3–5 个小片段，每个 1–2 行，配一个 emoji 开头
③ 一句今天想通的事（具体，不要说"要好好生活"）
标签：#城市 + #日常 + #季节/节日
```

## 7. 吐槽 / 差评

```
标题：对象 + 具体问题（不骂人，只写事实）
① 发生了什么：时间、地点、金额、对方说了什么
② 我的诉求是什么，对方怎么回应
③ 结果与现在的状态
④ 给后来人的提醒（怎么避免）
标签：#避坑 + #品类 + #城市
```

注意：只写可核实的经过，不写人身攻击、不写未经证实的猜测，指名商家时只描述自己经历的那一次。

## 8. 经验帖（我做了 N 次，总结出这几条）

```
标题：次数/年限 + 条数 + 收益
① 我的背景一句话（为什么我说的话有参考价值）
② 3–5 条经验，每条一个动作 + 一个反例
③ 最常见的一个误区
④ 如果只记一条，记哪条
标签：#经验 + #人群 + #领域
```
